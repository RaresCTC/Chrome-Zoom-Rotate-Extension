The following extension let's you zoom and rotate images within google chrome for an easier experience. 

This only works on images opened within new pages so it will not interfere with regular browsing. 

The extension let's you select which keys to use to rotate or reset the page. ( zooming in works by using the mouse wheel directly) 

It is created using JS, html and a bit of css. 

New versions are created regulary depending on my availabilty and new features / bugs that I think of. 

If you find any issue with it please do let me know so I can fix it =)).
